6. Database Schema Details

Detailed in the ER Diagrams section. Standard types used: BIGINT for IDs, VARCHAR for strings, DECIMAL(10,2) for currency, DATETIME for timestamps.

7. Design Patterns Used

  • API Gateway Pattern: Spring Cloud Gateway acts as a single entry point, abstracting internal microservices and handling cross-cutting concerns like JWT validation.
  • Database per Service: Ensures services are decoupled. User service has user_db, Product has product_db, etc.
  • Data Transfer Object (DTO): Ensures internal domain models (Entities) are not exposed directly to API clients.
  • Repository Pattern: Spring Data JPA abstracts data layer access.
  • Builder Pattern: Used heavily via Lombok's @Builder for constructing complex request/response objects and entities safely.
